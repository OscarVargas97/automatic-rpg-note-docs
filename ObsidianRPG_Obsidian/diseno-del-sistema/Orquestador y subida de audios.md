# Orquestador y subida de audios

Punto de entrada único para transcribir una sesión: sube uno o varios audios, dispara el
módulo de transcripción de `Pipeline de transcripción.md`, y deja el raw guardado en `raws/`
del vault destino. Nace vacía — [[Tema #3 — Orquestador y subida de audios para
transcripción]] la completa con el diseño real: stack de interfaz, cómo dispara el módulo, y
el punto de extensión para encadenar la ingesta con Claude cuando exista esa tarea.
